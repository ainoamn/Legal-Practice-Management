# إدارة المنصة — نطاق التنفيذ المؤكد

طلب المستخدم في 2026-11-03 تأكيد بناء Admin للتحكم في جميع مفاصل المنصة. تُرفع هذه الوحدة في الأولوية الآن مع الاحتفاظ ببقية خارطة المشروع. لا تعني إدارة المنصة منح الوصول الاعتيادي إلى ملفات القضايا أو مستندات المكاتب.

لوحة مستقلة `/admin` بهوية وجلسات وMFA وصلاحيات منفصلة عن مالك المكتب. الأقسام: مؤشرات حقيقية، المكاتب والتعليق/التفعيل، المستخدمون والتعطيل، الباقات وحدودها، الاشتراكات، فواتير المنصة والتحصيل اليدوي المرجعي، الصفحات والنشر، الدول والعملات، الهوية والتسجيل والدعم، مديرو المنصة وتفويض الصلاحيات، التدقيق ومراقبة الخدمات. لا دفع إلكتروني وهمي.

حساب `legal_platform` غير superuser ولا BYPASSRLS. يقرأ جداول المنصة ومناظر metadata محددة للمكاتب والمستخدمين فقط، دون كلمات مرورهم أو ملفاتهم. التعليق والتعطيل عبر دوال SQL ذات نطاق أعمدة محدد. الحساب العادي لا يقرأ جداول المديرين. جلسة مالك المكتب لا تفتح Admin. كل تغيير حساس يسجل باسم المدير؛ سجلات التدقيق append-only لحساب المنصة التشغيلي.

التحصيل اليدوي مرتبط بفاتورة وعملة، يمنع تجاوز المتبقي وتكرار المرجع. مالية المكتب والأمانات تعمل في وحدة مستقلة موضحة في LEGAL_OPERATIONS.md. حدود المستخدمين والقضايا والتخزين تطبق بالخادم؛ قياس التخزين يشمل كل إصدار محتفظ به، حتى المرفوض بالفحص. يمنع تخفيض الباقة دون الاستهلاك المقاس. AI لم ينفذ ولا تدعي حصته قياساً فعلياً.

المدير الأول عبر `npm run security:key` ثم `npm run admin:bootstrap`؛ تدخل كلمة المرور مخفية ولا تظهر في سطر الأوامر. bootstrap لا يستبدل مالكاً موجوداً. أول جلسة محصورة في إعداد MFA حتى تأكيد رمز صحيح. جلسات Admin لساعتين، وcookie مستقلة HttpOnly/SameSite=Strict مقيدة بمسار API المنصة. يمكن إنهاء الجلسات الأخرى ومراقبة جلسات المديرين وإلغاء المسموح منها. المالك الرئيسي محمي من التعطيل والتفويض عبر الواجهة.

المراقبة تعرض اتصال قاعدتي التشغيل وRedis وزمن الاستجابة والجلسات وسجل الأحداث وإعداد عمال المستندات؛ لا تدعي مراقبة نظام التشغيل أو تفاصيل أداء العمال. المؤشرات تشمل الموكلين والقضايا والجلسات والمهام والمستندات والعقود والوكالات والتراخيص واستهلاك الملفات دون محتواها القانوني. الاشتراك المنتهي/المعلق والتعليق الإداري يمنعان تعديل المكتب مع إبقاء القراءة. التحصيل محمي بمحفزات SQL تمنع التجاوز وإلغاء فاتورة محصلة، بالإضافة إلى الـlocks في الخدمة.

الصفحات تنشر/تسحب فعلياً وتظهر في `/pages` و`/pages/<slug>` كنص آمن بدلاً من HTML تنفيذي. اسم المنصة واللون والتسجيل العام يطبقان في مساحة المكتب. الدول والعملات والخانات العشرية قابلة للإدارة، مع منع تغيير عملة مستخدمة دون ترحيل. لا تخزن مفاتيح الخدمات في إعدادات عامة.

الاختبارات تشمل فصل الهويات، MFA، حظر SQL، صلاحيات موظف محدود، التحصيل المتزامن، النشر الآمن، تعطيل الحسابات، التدقيق والجلسات، وواجهة عربية/إنجليزية/هاتف. قوائم الاختيار مرتبطة بهوية المدير وتمسح عند تبديل الحسابات، فلا ترث صلاحيات حساب سابق.

المتبقي قبل الاعتماد التجاري: الدفع الإلكتروني وwebhooks والمصالحة/الاسترداد والخصومات والفوترة الدورية، تذاكر الدعم والوصول الاستثنائي المؤقت، ملفات الشعارات، مزودو AI وقياس حصصه، استرداد MFA للمديرين بإجراء مضبوط، المراقبة الشاملة والنسخ الاحتياطي والاستعادة والمراجعة الأمنية/القانونية. OCR المحلي يعمل بالفعل ولا يحتاج مفتاحاً خارجياً. التفاصيل والحدود المالية في LEGAL_OPERATIONS.md. الأقسام غير المنفذة لا تعرض كأزرار عاملة.
